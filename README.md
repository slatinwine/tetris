# 俄罗斯方块 Tetris

纯 HTML + CSS + JavaScript 实现的俄罗斯方块，单文件、零依赖、无构建步骤。

**在线试玩：https://slatinwine.github.io/tetris/**

## 功能

- 7-bag 随机出块，避免长时间等不到某一块
- 幽灵投影：半透明预览当前方块的落点
- Hold 暂存当前方块，Next 预览后续 3 块
- 消行计分：1/2/3/4 行 = 100/300/500/800 × 等级，软降 +1/格，硬降 +2/格
- 每 10 行升一级，下落速度递增；最高分保存在浏览器本地
- 键盘操作 + 移动端触屏按钮（长按连续移动），页面切到后台自动暂停

## 操作

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| ↑ / Z | 旋转 |
| ↓ | 软降 |
| 空格 | 硬降 |
| C | 暂存（Hold） |
| P | 暂停 |

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。
